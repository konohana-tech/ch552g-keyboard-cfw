安全設計: CH552 (family 0x11 / type 0x52) 以外は拒否。 config 書込 (0xA8) は送らない。bootloader 版が既知 (2.3.1/2.4.0–2.9.0) 以外は中断。 14,336B 超は拒否。書込後は必ずデバイス側ベリファイ (0xA6) を実行。
Linux udev (Vial用 1209:0001 とは別に必要。ISPモードは 4348:55E0 / 1a86:55e0): /etc/udev/rules.d/99-ch55x-isp.rules に以下2行。反映後、抜き差しして再試行。 SUBSYSTEM=="usb", ATTR{idVendor}=="4348", ATTR{idProduct}=="55e0", MODE="0666" SUBSYSTEM=="usb", ATTR{idVendor}=="1a86", ATTR{idProduct}=="55e0", MODE="0666"
